One X post promoting make.fun's make-your-own-bounty post. The post quotes or links https://x.com/makefunai/status/2124915864336236646, carries a photo of its own, make.fun or @makefunai, and the entrant's play code. Places go by the post's replies + reposts + quotes; the top 50 share $250.

`POST.json` names the post. The program (`main.ts`, Node 22, standard library only) copies it to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
